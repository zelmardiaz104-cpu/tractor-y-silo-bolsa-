# tractor-y-silo-bolsa-# 🚜 Tractor y silobolsa

Juego tipo "la culebrita": manejás un tractor, cosechás plantas de sorgo y el silobolsa crece detrás.

## Cómo se juega
- **Compu:** flechas o WASD para manejar, Espacio o P para pausar.
- **Celular:** deslizá el dedo sobre el campo o usá los botones de dirección.
- Empezás con 25 segundos y el reloj llega a 50 como máximo.
- Cada planta suma tiempo: 10 s al principio, y cada 5 plantas suma un 30% menos (mínimo 1,2 s).
- Si te salís por un borde, aparecés del otro lado. Si pasás por arriba de tu silobolsa, perdés.

## Cómo publicarlo
Es un solo archivo (`index.html`), sin dependencias. Activá GitHub Pages en
**Settings → Pages → Deploy from a branch → main / (root)**.
